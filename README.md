# オシロスコープ

中学1年理科「音の性質」の学習用オシロスコープです。単一のHTMLファイルとロゴ画像で動作し、サーバーや外部ライブラリーを必要としません。

## デザイン

ヘッダー左側にIWAKU2 PRIDEのロゴを配置しました。`iwaku2-logo.jpg` は `index.html` と同じフォルダーに置いてください。

## 機能

- 正弦波・矩形波・三角波・のこぎり波の表示と選択
- 振動数は0〜1,000 Hzを基本とし、上限を2,000 / 5,000 / 10,000 / 20,000 Hzに切り替え可能
- 振幅（0〜100%）を調整でき、音声出力を従来より大きく設定
- 設定に連動した音の高さ・大きさの目安表示と音声再生
- マイク入力の波形表示、入力レベルと振動数の概算
- マイク音声の録音、ページ内再生、ファイル保存
- スマートフォンやタブレットにも対応するレイアウト

## GitHub Pagesで公開する場合

1. `index.html`、`iwaku2-logo.jpg`、`README.md` をリポジトリのルートに置きます。
2. GitHubで **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、ブランチ `main`、フォルダー `/ (root)` を指定して保存します。
4. 表示されたHTTPSのサイトURLを開きます。マイクと録音はHTTPS上でブラウザーの許可を得て利用します。

## 使い方

振動数の上限を選び、スライダーを動かすと波形表示と数値が連動します。「音を再生」で音を聞き、停止できます。マイクまたは録音開始を押すとブラウザーが許可を求めます。録音はブラウザー上で処理され、保存ボタンで端末にダウンロードできます。

## 注意

- マイク・録音はHTTPS（またはローカル開発時のlocalhost）で利用できます。
- マイク入力と録音はブラウザーやOSの許可が必要です。許可を拒否した場合はアドレスバー付近のサイト設定から変更してください。
- 実際の音量は端末側の設定にも左右されます。耳を守るため、小さな音量から試してください。
- 20,000 Hz付近の音は、端末やスピーカーによって再生できない場合があります。
- 実マイク波形の振動数は、入力音が複数の音を含む場合などに正確に測れないことがあります。目安として扱ってください。
- 録音形式はブラウザーの対応状況に応じてWebM、Ogg、MP4のいずれかになります。
